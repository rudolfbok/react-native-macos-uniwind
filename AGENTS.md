This is a React Native app for macOS only, built on React Native macOS 0.83 (New Architecture) and styled with Uniwind (Tailwind CSS 4). There is no iOS or Android project.

## Layout

- `src/` — all app code. `App.tsx` is the root component; `global.css` holds Tailwind, Uniwind and the theme tokens.
- `macos/` — the native app generated by the official `react-native-macos` template: a SwiftUI shell in `App-macOS/AppDelegate.swift`, the Xcode project and the Podfile.
- `assets/icon.svg` — app icon source; the PNGs in `macos/App-macOS/Assets.xcassets/AppIcon.appiconset` are rendered from it.

## Commands

Use npm only, never pnpm, yarn or bun.

```bash
npm install
bundle install && bundle exec pod install --project-directory=macos   # after installing or upgrading native deps
npm start                                                             # Metro; run-macos doesn't start it
npm run macos                                                         # build and launch the app
npm run typecheck
npx react-native bundle --platform macos --dev false --entry-file index.js --bundle-output /tmp/main.jsbundle
```

CI runs the typecheck, the bundle above and an unsigned Release `xcodebuild`. Run `npm run typecheck` and the bundle command before declaring a task done.

## Rules

- `react-native-macos` decides the React Native version: keep `react-native` at the exact version in its peer dependencies, the `@react-native/*` packages on the same version, and `react` at the exact version React Native's renderer expects.
- `metro` and `metro-cache` are pinned devDependencies on React Native's Metro line, because Uniwind's `*` peer dependencies would otherwise pull a newer Metro and break bundling. Bump them together with React Native.
- Style with `className`. Colors come from the semantic tokens in `src/global.css` (`background`, `foreground`, `primary`, …); add new tokens there, in both the `light` and `dark` variants, instead of hardcoding colors.
- `Platform.OS` is `"macos"`. Use React Native primitives and libraries that support react-native-macos.
- The module name `App` appears in both `app.json` and `AppDelegate.swift`; change them together.
- Don't edit generated files: `src/uniwind-types.d.ts`, `macos/Pods/`, `macos/Podfile.lock`, `macos/App.xcworkspace`, `macos/PrivacyInfo.xcprivacy`.
